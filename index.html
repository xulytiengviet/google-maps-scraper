Công cụ trích xuất POI từ Google Map

Tìm kiếm và trích xuất điểm quan tâm (POI) theo chủ đề, tọa độ, bán kính, tuyến và địa giới; xuất CSV / JSON / GeoJSON.

GitHub

1. Backend API

URL này là địa chỉ HTTPS của backend chạy google-maps-scraper. Anh có thể lấy URL sau khi triển khai backend lên VPS/server riêng, Render, Fly.io, Railway, Google Cloud Run hoặc dịch vụ tương đương. Ví dụ: https://maps-api.tenmiencuaban.vn hoặc URL HTTPS do nền tảng triển khai cung cấp.

Notes: URL API chỉ được lưu trên trình duyệt cá nhân của anh bằng Local Storage, không được ghi vào repository hay gửi lên GitHub Pages.
